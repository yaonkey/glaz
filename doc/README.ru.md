# Glaz (Документация на русском)

CLI/TUI-приложение для наблюдения за логами по дням с группировкой однотипных ошибок.

## Возможности

- Группирует ошибки по ключу `уровень + нормализованный заголовок`.
- Отфильтровывает шум в заголовках (например, значения вроде `29#29`).
- Показывает время последнего появления, тип, количество и название ошибки.
- Поддерживает сортировку в мониторинге по `last`, `lvl`, `count`.
- В режиме текущего дня работает в realtime и подхватывает новые лог-файлы.
- Если за текущий день нет логов, при запуске автоматически открывает предыдущий день.
- Выделяет новые группы ошибок и показывает полный фрагмент записи.
- Имеет отдельный экран поиска по всем отслеживаемым файлам выбранной даты.

## Конфигурация

По умолчанию используется файл `glaz.json` в корне проекта.
Если файл отсутствует, он создается автоматически.

Пример:

```json
{
  "log_dirs": [
    "/home/yaonkey/Work/s/logs",
    "/home/yaonkey/Work/s/logs/nginx"
  ]
}
```

`log_dirs` — список директорий, где приложение ищет логи (включая php/nginx).

## Запуск

```bash
go run . -config glaz.json -date 2026-05-08
```

- `-config` — путь к JSON-конфигу.
- `-date` — дата логов в формате `YYYY-MM-DD`.

## Управление в TUI

- `↑/↓` или `j/k` — перемещение по текущему списку.
- `←/→` или `h/l` — переключение сортировки в режиме мониторинга.
- `/` — переключение между экранами мониторинга и поиска.
- `Enter` в режиме поиска — ввод/обновление поискового запроса.
- `d` — смена даты.
- `r` — обновление экрана.
- `q` — выход.
